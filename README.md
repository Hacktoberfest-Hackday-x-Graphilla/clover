# Kodiset-Local

Kodiset helps developers make their first open-source contribution with a plan matched to their level.

## Frontend (React + TypeScript + Tailwind)

```
npm install
npm run dev      # http://localhost:5173
npm test         # unit tests for level scoring
npm run build
```

Paste a GitHub repo link, take the level check, and get one suggested first contribution.
Add a Gemini API key in Settings for the plan explanations; GitHub facts work without it.
An optional GitHub token raises the API limit from about 60 to 5,000 requests per hour.
